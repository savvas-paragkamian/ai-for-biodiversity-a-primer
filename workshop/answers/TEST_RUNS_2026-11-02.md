# Test runs of 2 November 2026: the testing exercise (Chapter 14)

Run by an AI agent (Claude Code) on the author's behalf, in a scratch copy of
`workshop/testing/`, with the nine-field rules (`RULES.md`) and both note sets.
One pass of the procedure below; nothing was tuned between runs.

- Machine: MacBook Pro, Apple M1 Max, 32 GB. R 4.5.1, ellmer 0.5.0,
  Ollama 0.40.13. Model `qwen3:8b` (Q4_K_M), sampling temperature 0.6,
  top_p 0.95, top_k 20 (the model card's thinking-mode settings).
- Per set: the keyword baseline, three free runs (`run1` to `run3`) and two
  runs with seed 1 (`fixedA`, `fixedB`). Scored with `R/03_score.R`.
- The baseline was also run and scored under `LC_ALL=el_GR.UTF-8`
  (`score_dev_el.txt`): same result, 83 of 90.
- Timings: about 5 minutes per development run (10 notes) and 11 to 13
  minutes per held-out run (15 notes); other work was running on the machine.

Cells correct (exact binomial 95% interval in brackets; McNemar against the
baseline on the same cells):

| Run | Development, 10 notes, 90 cells | Held out, 15 notes, 135 cells |
|---|---|---|
| baseline | 83 (0.85 to 0.97) | 98 (0.64 to 0.80) |
| run1 | 74, p = 0.095 | 107, p = 0.27 |
| run2 | 75, p = 0.12 | 108, p = 0.20 |
| run3 | 72, p = 0.037 | 114, p = 0.034 |
| fixedA | 76, p = 0.19 | 115, p = 0.025 |
| fixedB | 76, identical output to fixedA | 115, identical output to fixedA |

The baseline's patterns were written with the development notes in view, so
it beats every model run there and falls behind all of them on the held-out
notes. The bootstrap intervals that resample notes (the unit of replication)
are wider than the binomial ones; both are in the score files.

Files: `testing-run-2026-11-02/dev/` and `heldout/` hold each run's CSV, its
settings sidecar (`.json`) and every raw response under `raw/`;
`score_*.txt` are the scorer's full output; `run.log` is the run script's log.
