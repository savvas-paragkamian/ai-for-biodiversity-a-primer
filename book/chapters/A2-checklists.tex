\chapter{Checklists}
\label{app:checklists}

\section{Before starting an AI-assisted project}

\begin{itemize}[label=$\square$]
  \item Data classified: what may go to a hosted service, what may not.
  \item Sensitive localities kept off hosted services, and generalised before
    they are shared or published.
  \item Taxonomic backbone named, with its version or date; coordinate
    reference system recorded.
  \item Samples and sequences: permits and country of origin recorded; terms
    checked to allow sharing, or sending to a service (\Cref{sec:abs}).
  \item \code{README.md} and \code{AGENTS.md} written.
  \item Git initialised; data and credentials excluded.
  \item \code{data/raw/} read-only and checksummed; environment pinned.
  \item Backup verified: three copies, two media, one off-site.
  \item Model chosen, hosted or local, and the reason recorded.
\end{itemize}

\section{Each agent session}

\begin{itemize}[label=$\square$]
  \item Before: checkpoint committed; agent started in the project directory; no
    credentials readable; task small enough to review in one sitting.
  \item After: whole diff read; new dependencies verified; code run and output
    inspected; row counts checked at every join; edge cases tried; run twice
    with identical output; result checked against domain sense.
  \item Prompt, model, version and settings logged; committed with a message.
  \item Notes the agent saved to memory reviewed; anything the project needs
    copied into \code{AGENTS.md} or a committed notes folder
    (\Cref{ch:agentic}).
  \item For an analysis: plan written before the session; every model fitted
    logged; result checked under other reasonable choices
    (\Cref{sec:analysis}).
\end{itemize}

\section{Testing a model or assistant}

\begin{itemize}[label=$\square$]
  \item Expert-written questions with expected answers and sources.
  \item Answer key annotated twice, with the agreement reported; what counts as
    good enough decided before the test.
  \item Test items held out before any rule, prompt or baseline is tuned.
  \item Unit of replication decided: the note or document, not the cell.
  \item Enough items for the decision, with an interval reported beside each
    score.
  \item Two systems compared on the same items, with a paired test.
  \item Repeated runs, with their spread; abstentions and malformed outputs
    counted.
  \item Grounding: every claim supported by what was retrieved.
  \item Citations: each cited source says what it is cited for.
  \item Pushback: a correct answer survives a confident false challenge.
  \item Memorisation controls: invented names or deepest-rank items; results
    reported per field and per rank; reference versions recorded for the key
    and the system.
  \item Cost per answer recorded; results compared with the previous version.
\end{itemize}

\section{Before submitting a manuscript}

\begin{itemize}[label=$\square$]
  \item Every DOI resolves and its title matches; others checked by hand.
  \item Every cited paper opened, and the claim matches what it says.
  \item AI use disclosed specifically: model, version, date, purpose, checks.
  \item Every field a model extracted or classified has a validation sample
    and its error rates reported; machine-derived records flagged as such
    before deposit (\Cref{sec:outputasdata}).
  \item Accessions and dataset DOIs cited; reference database and taxonomy
    versions recorded in the methods.
  \item Code and prompts archived with a DOI; data deposited.
  \item No confidential material sent to a hosted service.
  \item Every author can explain and support every claim.
\end{itemize}

\section{Before reviewing a manuscript}

\begin{itemize}[label=$\square$]
  \item Journal policy on AI in peer review checked.
  \item Manuscript not uploaded to any hosted service. Local model or none.
  \item The judgement of soundness is yours.
\end{itemize}

\section{Institutional AI policy: minimum contents}

\begin{itemize}[label=$\square$]
  \item Data classification rules, with specifics.
  \item Approved tools, each with a named owner.
  \item Disclosure requirements for publications; no hosted services in review.
  \item Agent sandboxing; no production access; credential rotation.
  \item Procurement: does the vendor train on submitted data?
  \item A date for the next review, with an annual review as the starting point.
\end{itemize}
