collected in the author's notes and literature folder while writing this book.
Titles and names are as
YouTube, GitHub and the publishers' own sites gave them in September 2026;
repositories that have moved are listed at their current address. Web material
is taken down and renamed more often than papers, so some links will break.

\section{Tool repositories}

\subsection{Agents}

\begin{itemize}
  \item \emph{OpenCode}: a coding agent for the terminal.\\
    \url{https://github.com/anomalyco/opencode}
  \item \emph{OpenHands}: a coding agent.\\
    \url{https://github.com/OpenHands/OpenHands}
  \item \emph{Goose}: an extensible agent that installs, runs and edits code.\\
    \url{https://github.com/aaif-goose/goose}
  \item \emph{OpenClaw}: a general-purpose personal agent.\\
    \url{https://github.com/openclaw/openclaw}
  \item \emph{OpenViking}: a store for agent memory, retrieval and skills.\\
    \url{https://github.com/volcengine/OpenViking}
\end{itemize}

\subsection{Running models locally}

\begin{itemize}
  \item \emph{textgen} (formerly text-generation-webui): a desktop app for
    local models.\\
    \url{https://github.com/oobabooga/textgen}
  \item \emph{colibri}: runs large mixture-of-experts models on ordinary
    hardware by reading parts of the model from disk.\\
    \url{https://github.com/JustVugg/colibri}
  \item \emph{whisper.cpp}: speech-to-text on your own machine.\\
    \url{https://github.com/ggml-org/whisper.cpp}
  \item \emph{The Art of the Terminal}: see its \code{use-local-llms-already}
    folder, a guide to running local models.\\
    \url{https://github.com/vivus-ignis/the-art-of-the-terminal}
\end{itemize}
